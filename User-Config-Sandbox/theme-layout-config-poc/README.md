# nLab — Configuration Sandbox

Ce dossier sert de cible de test pour les configurations du Webmaster Preview.

- Il est volontairement placé hors de `Preview-Web-Sandbox/` : il n'apparaît pas dans la galerie publique du site.
- Son contenu reste public parce qu'il appartient au dépôt public.
- Aucun secret, jeton GitHub ou donnée privée ne doit y être enregistré.
- La page de test exporte un JSON compatible avec ce dossier. L'écriture directe depuis le navigateur reste désactivée tant qu'une authentification GitHub App/OAuth avec permissions minimales n'est pas disponible.

La phase suivante pourra déplacer le même schéma vers un dépôt privé après validation de l'authentification et des règles d'accès.
